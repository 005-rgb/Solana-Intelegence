HTTP response

Belum ada validasi lengkap untuk:

field type

non-finite values
timestamp bounds
clock skew
pair identity consistency
invalid record status
schema revision
malformed record yang harus disimpan sebagai INVALID
Contoh masalah:

payload JSON valid tetapi bukan array

dapat diperlakukan sebagai feed kosong, bukan sebagai INVALID atau provider schema error.

volume: {}

Blueprint Phase 1 mensyaratkan missing field disimpan sebagai null plus quality reason, bukan object kosong yang bisa terlihat seperti field tersedia.

UNKNOWN_ACCOUNT
